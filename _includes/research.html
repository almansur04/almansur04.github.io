ML-Driven Load Balancing and Radio Resource Management for 5G SONs

Sep 2024 - Jun 2025
TL;DR Under Review for International Conference on Secure and Intelligent Digital Ecosystems. Built an explainable ML pipeline for near-RT RIC deployment that predicts 5G congestion and automates load balancing via CIO steering in 8.5 ms.

Proposed an automated, explainable machine learning pipeline for proactive mobile load balancing and QoE prediction using real-world 5G telemetry from Astana. Utilized SMOTE to address class imbalance and trained ensemble models to estimate response latency and throughput. Implemented Tree-based SHAP analysis to enable an operational policy distinguishing coverage from congestion-driven degradation for targeted Cell Individual Offset (CIO) steering, achieving an inference pipeline averaging 8.5 ms per sample for near-RT RIC deployment.
