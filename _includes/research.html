Separating Device Effects from Cellular Network Performance Using Cellular Telemetry Segmentation

Apr 2026 - Jun 2026
TL;DR Isolated network degradation from device constraints by analyzing 1M+ web sessions using statistical segmentation, providing a framework for targeted infrastructure upgrades.

Analyzed one million mobile web sessions collected by a cellular operator in Kazakhstan to distinguish network degradation from device-related variation. Applied Kruskal-Wallis and Dunn tests with Bonferroni correction on a restricted dataset of 40,439 sessions to identify significant throughput differences. Developed a practical framework for prioritizing infrastructure improvements by classifying active cells using a −95 dBm signal-strength threshold to isolate coverage-related issues from capacity congestion.

ML-Driven Load Balancing and Radio Resource Management for 5G SONs

Sep 2024 - Jun 2025
TL;DR Built an explainable ML pipeline for near-RT RIC deployment that predicts 5G congestion and automates load balancing via CIO steering in 8.5 ms.

Proposed an automated, explainable machine learning pipeline for proactive mobile load balancing and QoE prediction using real-world 5G telemetry from Astana. Utilized SMOTE to address class imbalance and trained ensemble models to estimate response latency and throughput. Implemented Tree-based SHAP analysis to enable an operational policy distinguishing coverage from congestion-driven degradation for targeted Cell Individual Offset (CIO) steering, achieving an inference pipeline averaging 8.5 ms per sample for near-RT RIC deployment.
