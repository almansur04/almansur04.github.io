Separating Device Effects from Cellular Network Performance Using Cellular Telemetry Segmentation

Apr 2026 — Jun 2026

Analyzed one million mobile web sessions collected by a cellular operator in Kazakhstan to distinguish network degradation from device-related variation. Applied Kruskal-Wallis and Dunn tests with Bonferroni correction on a restricted dataset to identify significant throughput differences across device models. Developed a practical framework for prioritizing cellular infrastructure improvements by classifying active cells using signal-strength thresholds to isolate coverage-related issues from capacity congestion.

ML-Driven Load Balancing and Radio Resource Management for 5G SONs (BSc Thesis)

Sep 2024 — Jun 2025

Proposed an automated, explainable machine learning pipeline for proactive mobile load balancing and QoE prediction using real-world 5G telemetry from Astana. Utilized SMOTE to address class imbalance and trained ensemble models (Random Forest, LightGBM) to estimate response latency and throughput. Implemented Tree-based SHAP analysis to enable an operational policy distinguishing coverage from congestion-driven degradation for targeted Cell Individual Offset (CIO) steering, achieving an inference pipeline averaging 8.5 ms per sample for near-RT RIC deployment.
